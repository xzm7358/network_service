# EEP Brownfield Adoption

This repository is being adopted into Embedded Engineering Platform (EEP) as a brownfield product.

- Platform release: `1.20.0`
- Baseline product commit: `0b415f57c9bf2519645099513f7b73c18a174e8b`
- Service profile: `process`
- Contract profile: `ipc`
- UI profile: `none`

The baseline commit predates EEP metadata and remains the immutable source point for adoption comparison. The current adoption does not assert that Network IPC v1 or production target/HIL verification is complete.

Product-owned source code remains product-owned. EEP metadata records adopted standards, deviations and verification requirements; it must not silently overwrite runtime implementation.
